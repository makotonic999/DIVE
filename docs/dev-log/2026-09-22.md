### 強調表示崩れの修正メモ（再発時のため）
- 原因: CommonMark の flanking 規則。閉じ `**` の直後が全角約物/日本語だと閉じない。開き `**` の直後が開き括弧 `「（` だと開かない。
- 対策ルール: **括弧類は常に強調の外に置く**（例: `「**テキスト**」`、`**テキスト**（補足）`）。
- 検出方法: `npm run build` 後、`dist/chapters/*/index.html` を `**`（`color:#` を含むコードハイライト行は除外）で grep し、残っていれば表示崩れ。ゼロが正常。
- 一括スクリプトは正常箇所まで壊すため不採用。壊れ箇所を個別修正するのが安全。
