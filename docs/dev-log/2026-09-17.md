# 2026-09-17 作業ログ

## 概要
DIVEプロジェクト（Astro + MDX + AWS Terraform）のPhase 1初期構築を完了した。

---

## やったこと

### 1. Astroプロジェクト基盤の構築

- `astro.config.mjs` — Shiki（コードハイライト）+ remark-math / rehype-katex（数式）の設定を組み込み
- `tailwind.config.mjs` — Tailwind CSS + @tailwindcss/typography の設定
- `package.json` — 依存パッケージの定義（後にastro 5.7.13 → 5.18.2へ脆弱性対応アップグレード）

### 2. BookLayout（紙の本デザイン）

- `src/layouts/BookLayout.astro` を作成
  - 背景色 `#FBF9F5`、テキスト `#2C2C2C`、最大幅 `700px` の中央配置
  - フォント: Noto Serif JP（本文）/ Noto Sans JP（UI）/ JetBrains Mono（コード）
  - KaTeX CSSをCDNから読み込み
  - sticky ヘッダー、フッター付き
  - Props: `title`, `description`, `part`, `chapter`, `publishedAt`

### 3. コンテンツコレクション定義

- `src/content/config.ts` — Zodスキーマで章のフロントマターを型安全に管理
  - `chapter`（1–21）、`part`（1–7）、`difficulty`、`readingTimeMinutes` 等

### 4. トップページ（目次）

- `src/pages/index.astro` — 全7Part / 21章のシラバスを表示
  - 章ごとにMDXが存在すればリンク、なければ「執筆準備中」と表示

### 5. 第1章サンプルコンテンツ

- `src/content/chapters/ch01.mdx` — 「0と1の世界」
  - KaTeX数式: 電圧の論理レベル定義、ブール代数、二進数変換
  - Shikiコードブロック: Python（bin/int変換）、C（ビット演算）
  - Markdownテーブル: 半加算器の真理値表

### 6. 動的ルーティング

- `src/pages/chapters/[slug].astro` — `/chapters/ch01` などの章URLを生成
  - `getStaticPaths()` でコレクション全章を静的ページとして出力
  - 「目次へ戻る」ナビゲーション付き

### 7. Terraformインフラ定義

- `terraform/variables.tf` — リージョン、バケット名、CloudFront価格クラス等の変数
- `terraform/main.tf` — S3（プライベート + SSE-S3）+ CloudFront OAC（SigV4）+ バケットポリシー
- `terraform/outputs.tf` — CloudFrontドメイン、S3バケット名、デプロイコマンドサンプルの出力

### 8. 環境構築

- Node.js v24.21.0 / npm v11.19.0 をChocolatey経由でインストール
- `npm install` で421パッケージを導入
- Astroを5.7.13 → 5.18.2に脆弱性対応アップグレード（`npm audit`で検出）

## 技術メモ

**OAC vs OAI**: S3オリジンへのアクセス制御はOAI（旧方式）ではなくOAC（新方式・SigV4署名）を採用。AWSが推奨する現在のベストプラクティス。

**Astroの脆弱性**: `npm audit`で5件検出。astro 5.x の範囲内での修正は5.18.2まで。完全修正にはv7へのメジャーアップグレードが必要（ブレーキングチェンジのため今回は保留）。esbuildのGHSA-g7r4-m6w7-qqqrはWindowsの開発サーバーのみ影響するが、静的ビルドとS3デプロイのみの運用なので実害なし。
